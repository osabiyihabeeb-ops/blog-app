# 🐦 Mini Twitter - Blog Application

A Twitter-like blog app where you can post, like, and delete posts. Built with React!

[React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
[Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)
[JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## ✨ Features

- ✅ **Create a new post (tweet)** - Write up to 280 characters
- 📜 **Display all posts** - Feed shows newest first
- ❤️ **Like a post** - Click heart to like/unlike, count updates instantly
- 🗑️ **Delete your own post** - Delete button only shows on YOUR posts
- 💾 **Auto-save** - Posts stay after refresh with `localStorage`
- 📱 **Responsive** - Works on phone & desktop
- 🔢 **Character Counter** - Turns red when you're almost out

## 🛠️ Tech Stack

- **React** - UI Library
- **Vite** - Build Tool
- **JavaScript (ES6+)** - Logic
- **CSS** - Twitter-style design
- **localStorage** - Data Persistence

## 🚀 How To Run It Locally 

```bash
# 1. Clone the repo
git clone https://github.com/osabiyihabeeb-ops/blog-app.git

# 2. Go into the folder
cd blog-app

# 3. Install packages
npm install

# 4. Start the app
npm run dev
